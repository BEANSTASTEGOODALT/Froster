# Froster
## A proof of concept extension for a Dr. Frost tool

# Installation:

* Go to chrome://extensions
* Click the "Developer Mode" toggle in top right
* Download from here (Code -> Download as zip)
* Go into files -> Extract all
* Close files and go back to chrome://extensions
* Click "Load unpacked"
* Find where you saved Froster
* Double click into it until there's no folders
* Click "Open"
* Close the tab
